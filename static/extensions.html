用你自己登录的浏览器生成 reCAPTCHA token，不需要第三方打码服务。

下载打码扩展

安装步骤

  1. 1. 下载并解压 ZIP。
  2. 2. 打开 chrome://extensions，开启「开发者模式」，点「加载已解压的扩展程序」，选择解压出的文件夹。
  3. 3. 打开扩展的「选项」，WebSocket 填 ws://127.0.0.1:8000/captcha_ws，API Key 填上方的值，Route Key 留空。
  4. 4. 回到本页点「测试扩展」，状态变成「已连接」就完成了。
